# 织见 L1（0.11.0）实施与验证

基线：K8.5 / 0.10.5 / c78a743。工作分支：codex/l1。原 K8.5 发行目录保留。本次不做整体 UI 与布局重设计。

## 已实现

- AI API 2.0：异步返回保存结果，失败回滚，批量原子操作，严格目标及参数检查，有向关系反向不再误合并；requestId 支持会话内最近 128 次操作防重。
- AI skill：应用导出文档与随包 skill 共用来源；解析器完整保留详情、批注、归属、来源、阅读路径，检测循环和断链。安装时升级未修改的托管文件，保留用户修改文件并将新版放在 `.updates/L1`。
- 导出关系：schemaVersion 3 保留来源卡、资料目录、跨画布引用和阅读路径。单画布之外的跳转保留原目标信息、提示待关联，关系工具提供重新关联入口。兼容旧格式导入。
- 保存恢复：项目结构改为 IndexedDB 异步事务提交，保留 K8.5 原始存档及迁移日志；加载失败停止覆盖。恢复中心保留最近 10 个 L1 版本，附件按内容指纹去重，旧版恢复记录仍可读取。
- 大附件：4 MiB 分块跨进程传输，后台流式压缩/解压，校验传输长度，支持取消和失败清理。当前限制为单附件 512 MiB、附件总量 2 GiB、结构 JSON 16 MiB、附件数量 10000。
- PDF：可选文字层、按页摘录、页码回跳、原文高亮和内容指纹；原文件变化时提醒核对。
- 资料使用位置：资料右键菜单可查看材料卡片、摘录、关系证据及预览的引用位置；删除前显示影响并创建恢复点。
- 关系分析：按类型和方向查看关系、寻找最短关系路径、保存阅读路径并逐步定位；阅读路径随项目导出。
- 穿透搜索：顶部搜索或 Ctrl+F，跨项目与画布检索元素、详情、便签、元素/关系批注、来源引文、附件名称与可提取正文。支持文字 PDF、DOCX 正文及批注、表格单元格/公式、PPTX 幻灯片/备注、文本与代码；结果附画布、页码或单元格位置。
- 保留 K8.5 安装版图标修复：默认轻拟物叠合元素，任务栏/快捷方式与 .fantin 图标切换、失败反馈。

## 已知边界

- 未集成 OCR 或语音转文字。扫描 PDF、图片、音视频和不支持格式明确列为未完整检索；网页链接只检索本地网址和信息，不自动抓取网页全文。
- 附件正文首次检索需提取文字并建立缓存；大型文档解析仍会使用相应解析库所需内存。分块传输不等同于所有解析过程恒定内存。最大 512 MiB/2 GiB 边界尚未做满量压力实测。
- 阅读路径目前在当前画布关系图中生成；包外步骤和外部跳转需要用户重新关联，不能自动猜测目标。
- 1010 元素密集场景的离屏压力测试通过功能检查，但最长帧间隔约 617 ms，仍有优化空间；本版本不宣称已解决全部大画布性能问题。
- 安装回归覆盖打包成品、安装相关图标/快捷方式/注册表逻辑及数据迁移，未在干净 Windows 虚拟机中实走整套安装、覆盖升级和卸载。
- L1 新存档不供旧版本直接写入。回退 K8.5 会读取保留的升级前存档，不能自动看到 L1 新增编辑；重要修改请先导出备份。

## 使用入口

穿透搜索：顶部搜索框 / Ctrl+F。PDF 摘录：选择文字后点击“摘录所选文字”或 Ctrl+Shift+E。资料引用：资料右键“使用位置”。关系路径：右下角“关系检查”→“关系分析与阅读路径”。AI 指引：设置→AI→导出完整指引。
