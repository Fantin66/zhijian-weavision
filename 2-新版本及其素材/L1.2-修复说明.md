# L1.2（0.11.2）搜索复原与 Markdown 预览修正

## 修复

- 搜索记录临时展开前的状态。切换结果、分类、范围、关键词，关闭预览、退出搜索或切换画布时，恢复元素和附件的原尺寸、位置及折叠状态。
- 节点详情展开造成的邻近元素位移一起恢复；连续快速切换会取消尚未结束的展开动画，避免旧动画再次改动布局。
- 原本已经展开的节点和附件保持展开。搜索为定位临时展开的父节点恢复原折叠状态。
- 搜索临时几何状态不写入自动存档，不给附件展开增加撤销记录；AI 写操作前清理搜索预览。
- MD / Markdown 附件搜索使用平时的 Markdown 渲染器。画布中直接给已有即时预览加高亮，不替换预览节点，保留标题、列表、粗体等格式。搜索结束移除高亮。
- 从搜索框或预览区按 Esc 均可退出并复原。

## 验证

33 项搜索专项回归通过；32 项应用集成回归通过；13 项基础回归通过。覆盖关闭/预先展开状态、尺寸恢复、邻近元素归位、快速切换、跨画布、父级折叠、自动存档与 Markdown DOM 复用。
