# 白天看 BP，晚上我做了个投研工具和一款投资题材游戏

我是一级市场投资经理。

白天大部分时间在干嘛？看 BP。一天几十份上百份地翻，绝大多数扫两眼就过，能往下走的没几个。真碰到一个想跟的，才进尽调——把这家公司从里到外翻一遍：股权怎么搭的，历史沿革里出过什么事，应收账款和关联交易压在哪儿，技术是真行还是讲故事。

干久了你会撞上一件挺尴尬的事：材料一大堆，趁手的工具几乎没有。

你想在几十份材料里理清几件事的关系。Word 信息密，可你得来回翻着找；PPT 是好看，框架一搭细节就没了；Excel 能算账，讲不了故事；思维导图画得了结构，附件塞不进去，发出去人家还得自己装软件。

白天遇到的问题，晚上我就自己动手解决。

我做了个东西，叫织见。说真的不是又一个笔记软件。我就想干一件特别具体的事：把尽调里散在各处的材料——附件、网页、笔记、图片——连到一起，能看清彼此的关系；但又能随时钻进其中任意一项，把它展开看清楚，看完了收回去。

还有一件我自己挺得意的：这些最后能打成一个文件，直接发同事。对面打开就是完整的、各部分对得上的关系图，不是一张截图，也不用人家自己去装软件。

白天我拆解的东西，晚上变成了一个能用的玩意儿。

但光有工具不够。有些事工具讲不清，得拿故事讲。

我又在做一款游戏，叫投×。滑卡叙事游戏，背景是国企股权投资。你演一个投资经理，在领导、派系、项目、合规、廉政和自己底线之间不停做选择。

"投"这个字在游戏里不只是投项目。它是投胎——起点不同，退路就不同；是投名状——你得拿项目和表态向组织证明自己；也是投机，在不确定里赌风向赌人事；还有投靠，找个能罩住你的领导或流程；到头来很可能是投降——一次次妥协下来，你早就不问最初那个问题了。

这游戏不打算回答"怎么投才对"。它想让人感觉到：你以为自己在投项目，其实很多时候你在投命、投人、投势，甚至就是在投降。

荒诞，但都是真的。

有人会问，你一个做投资的，怎么又做工具又做游戏。

其实是一回事，都是我在拆这行——它到底怎么转的。

织见是理性那一半：材料理清、关系对上、判断变成能传的东西。投×是讽刺那一半：让你去体验，一个没法简单定罪的项目黄了之后，所有人怎么为了活下去，把复杂的真相改写成对自己有利的版本。

一个讲怎么看清，一个讲看清之后你拿它怎么办。

我开这个号，想发三样东西。

行业观点。我每天看 BP、做尽调攒下来的真实案例和一二级市场观察，这是我最熟、也想多说的。

织见的开发和使用。怎么把工具做出来、怎么拿它做投研，我会一直写。已经放 GitHub 上了，源码公开，免费，非商用。

投×的世界观和美术。游戏还在做，但世界观、角色、美术设定集已经齐了，我会先发这些。游戏得慢慢来，概念可以先看。

说到底这三样是一回事：一个干投资的人，怎么把他看到的这行，拆给你看。
