# 被一级市场逼成全栈：
# 白天看100份BP，晚上写代码做游戏

先自我介绍：国资背景基金，一级市场，投资经理。听着是不是像那么回事。

翻译一下：一个主要工作是看PPT和挑刺的人。人称PPT鉴定师、故事打假办、尽调苦力。

外人想象的投资人：头等舱，五星酒店，和创始人喝咖啡，聊的都是星辰大海。

我们实际干的：写纪要、开会、填表，偶尔出差尽调——高铁二等座到厂区门口，等财务总监开完会才有空搭理你。

BP才是日常大头。一天扫一百份，大多撑到第三页就想关——碍于礼貌看完，默默归档进“暂不关注”。扫多了还能总结出规律：前年一水的“国产替代”，去年全换“大模型赋能一切”，今年轮到“具身智能替你上班”。赛道换着花样火，BP换着花样写，结尾永远是同一句：我们壁垒很高，就差你一个懂行的。

偶尔真碰上看着能往下走的，好日子就来了——进尽调。

尽调这词听着高级，干起来是把公司连底裤翻出来看：股权怎么搭的，历史沿革里出过什么事，老板拍着胸脯那句“明年翻三倍”是真订单还是PPT上画的，应收账款和关联交易藏在哪个抽屉里。

翻多了悟出个真理：尽调跟相亲一样，了解得越深，越不想投。有的项目查完只剩叹气——问题比估值还多，估值倒是敢要，跟营收压根不是一个量级。

别以为我们天天琢磨怎么赚钱，那也太天真了。

国资体系里，我们更多时间琢磨的是：这项目要是黄了，责任怎么划；纪要怎么写，才能显得专业又不担责；这个会到底开不开，开了记不记，记了签不签。

钱是国家的，责任是自己的。这笔账，谁心里都门儿清。

所以你能在国企看到一种奇观：会上都说“项目不错，可以推进”，真到签字那一步，全体突然开始研究自己的茶杯。

心累完还有身累——材料是真的多。

一天几十份BP，加访谈纪要、财报、各种聊天截图，几百个文件，散在网盘、邮箱、微信文件传输助手，和一个叫“新建文件夹(3)”的地方。想查证点什么——比如这老板上个月说的话跟这个月对不对得上——先得把这几个地方挨个翻一遍。

Word能查，翻起来费眼；Excel会算账，讲不了故事；思维导图画得规整，就是太死板。PPT最好看——做BP的拿手活嘛，比我们给领导写的汇报精致多了。

被材料折磨到第N个晚上，我想明白了：抱怨没用，没人做，就自己做。

于是有了织见（Weavision）。不是什么高大上的东西，就是把散在各处的文件、网页、笔记、图片串到一块儿，谁跟谁有关系，一眼能看见；想细看就展开，看完收回来。像整理房间，只不过整理的是思路和材料。

最得意的是能打包成一个文件甩给同事，对方打开就是一张整图，不用注册账号、不用装软件，也不怕打不开。“我发你了，你怎么打不开”这种职场经典悲剧，总算轮不到我演了。

厉害吗？谈不上。它是被一百份BP和三千个散落文件逼出来的。

Vibe coding 做的。白天我问创始人“凭什么”——凭什么是你，凭什么这个估值。晚上换了位置，AI问我“做什么”，这题我居然也得想一阵。工具嘛，能解决自己的问题就行。

不过，做工具的快乐，解决不了白天的憋屈。有些话，工具说不出来，得换个方式说。

于是我又在做一款游戏，叫“投X”。

对，一个做投资的，业余做一款讽刺投资行业的游戏。会上不敢说的话，全塞游戏里了。

（照例 vibe coding。我出世界观和憋屈，它出代码。）

玩法很简单：屏幕上弹出一张卡，往左划、往右划，一个决定就出去了，收不回来——跟你在会上说错一句话一样。

你演一个投资经理：上头有领导，身边有派系，手上有项目，脑子里绷着合规和廉政的弦，心里还压着一条底线。每张卡都在逼你选：站队，还是站对？汇报，还是隐瞒？签字，还是装死？

“投”这个字，在游戏里远不止“投项目”那点事：

是投胎。生在这个体系里，你的起点、退路、输不输得起，都不一样。

是投名状。你得不停拿项目、拿表态，向组织证明自己还有用。

是投机。政策、风向、人事，在不确定里赌，赌错了也没人替你兜底。

是投靠。总得找个能罩住你的领导，或者一套流程、一个派系，不然你连自己怎么没的都不知道。

到后来，多半就是投降。一次次妥协之后，你早就不问最初那个问题了。

这游戏不打算教你怎么投才对，它只想让你玩着玩着，突然笑不出来。

荒诞吗？荒诞。真实吗？干这行的人，懂的都懂。

这个号之后大概发三样东西。

行业里的真事儿。尽调完不想投的故事、一级市场的观察，放心，会隐去姓名和单位。非要自己对号入座的，我也拦不住。

织见怎么用、怎么做出来的。源码已经在GitHub上，开源、免费，非商用随便用。没指着它赚钱，能帮一个被材料折磨的同行是一个。

投X的世界观和美术。游戏还在慢慢做，但设定集攒了不少，可以先看看概念。

白天我是国资基金的投资经理，拆别人的项目；晚上做游戏、写这个号，拆这个行业。

想看的关注一下。万一你也是被材料、被会议、被“再研究研究”折磨过的人，咱们互相认个亲。
