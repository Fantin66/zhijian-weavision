# 织见 Weavision · 思维关系板

> 织连万象，见聚一隅。

思维导图是树，关系只有父子。文件合集是堆，文件之间没关系。织见是一张关系网——元素和线任意组合，线带方向和语义。

任何元素——一行判断、一页文档、一张便签、一个网页——都能用带方向的线连起来。线有五种语义：支撑、导致、反证、证据、关联。图大了就聚焦——选中一个点，只留直接关系，其余退为背景。节点可以原地展开成阅读区，不弹窗、不跳转。每个元素和每条线都能写批注——标题只是入口，内容才是本体。

## 功能

- 五种语义关系：关联 / 支撑 / 导致 / 反证 / 证据
- 跨层级自由连线，不受树状结构限制
- 聚焦切换：选中节点，只留直接关系
- 就地形变：节点 / 附件原地展开为阅读区
- 跨画布跃迁
- 板→文 Markdown 导出
- .fantin 文件格式（ZIP，含全部画布 + 附件）
- AI 编排接口（37 条命令）
- Win11 Fluent Design 材质系统
